
# simple_qt_game

一个用 Qt 6 (C++17) 写的 2D 横版闯关小游戏。玩家控制一只小恐龙，在布满墙壁、
陷阱和开关的地图里寻找通关区域，同时躲避伤害。

## 运行方式

用 Qt Creator 打开 `tryGame.pro`，选择 Qt 6 的 MinGW 64-bit 套件，直接运行即可。

命令行构建：

```bash
qmake tryGame.pro
mingw32-make        # 或 nmake / make，取决于你的环境
```

编译产物在 `build/` 目录下，可执行文件为 `tryGame.exe`。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 上下左右移动 |
| `J` | 攻击（也能打开关、在通关区互动） |
| `空格` | 闪避冲刺（有冷却） |
| `空格` | 死亡或通关后重新开始 |

按住方向键的同时按 `J` 会触发「移动攻击」动作。

## 玩法

- 初始生命 100 点，碰到陷阱会掉血并进入短暂无敌帧，生命归零即游戏结束。
- 灰色方块是开关，用 `J` 攻击后变绿，对应的深红色开关门会消失，打开新的通路。
- 右下角的绿色区域是终点，站进去按 `J` 通关。
- 陷阱分固定和移动两种，移动陷阱会沿设定路径来回巡逻，注意节奏和走位。

## 项目结构

```
tryGame.pro          工程文件
main.cpp             程序入口，启动登录界面
dialog.*             开始界面（开始游戏 / 教程）
teacher.*            教程界面
mainwindow.*         游戏主逻辑：地图、动作系统、陷阱、碰撞、UI 绘制
gameswitch.*         开关与开关门
Trap.* / MovingTrap.* 固定陷阱与可移动陷阱
SpriteAnimation.*    精灵图序列帧动画
image/               图片素材（恐龙、翼龙、背景、登录图）
```
